# SyncGen

A poerful Streamlit app that uses LLM to generate image via prompts.
This app allows users to enter a prompt, enchance the user prompt given, pass the prompt to an LLM for the Generation to happen.
We will be using Bria AI's API for generating the image since we don't have the compute power.

## Features
1. Generate UHQ images from text prompts
2. Remove background.
3. Prompt Enhancements.
